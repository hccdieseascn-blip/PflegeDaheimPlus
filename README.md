# PflegeDaheim+

Prototype UAS für digitale häusliche Pflege älterer Menschen in Deutschland.

## Start
Entpacken → Ordner in VS Code öffnen → `index.html` mit Live Server öffnen.
Kein Backend erforderlich.

## Rollen
- Lansia / Patient
- Pflegefachperson
- Angehörige

## Hauptziel des Prototyps
Der Workflow ist miteinander verbunden: **Vitalzeichen hinzufügen → bei erhöhtem Blutdruck automatische Warnung → Pflegeteam informieren → Meldung erscheint in der Pflegeansicht → Pflegebericht dokumentieren.**

## Interaktiv
Profil bearbeiten, Vitalzeichen hinzufügen, Medikamentenplan verwalten, Sturzrisiko prüfen, Wohnungssicherheit, Tagesplan, Telemedizin-Simulation, Pflegeberichte, Nachrichten, Angehörigenansicht und SOS-Demo. Daten werden im Browser per `localStorage` gespeichert.

Hinweis: UI-/Funktionsprototyp, keine echte medizinische Entscheidungsunterstützung, kein echter Notruf und keine echte Videoverbindung.
